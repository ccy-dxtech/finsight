# Button

모든 버튼은 `radius-pill` 필 모양, `button` 스타일이에요.

`<button class="fs-btn fs-btn--primary">시작하기</button>` — 사용하는 쪽에서 라벨(2~6자, 해요체가 아닌 명사형·동사형 짧은 말: "시작하기", "프로 구독하기")과 선택적 아이콘을 넣어요.

| 변형 | 클래스 | 쓰는 곳 |
|---|---|---|
| 주요 | `fs-btn--primary` | 화면당 하나뿐인 핵심 동작 |
| 큰 주요 | `+ fs-btn--lg` | 랜딩 히어로, 요금제, 로그인 |
| 보조 | `fs-btn--secondary` | 함께 놓이는 두 번째 동작 |
| 텍스트 | `fs-btn--text` | "전체 보기" 같은 링크형 |
| Google | `fs-btn--google` | `/login`의 단 하나의 버튼 |
| 위험 | `fs-btn--danger` | 내 데이터 전체 삭제(확인 대화상자 필수) |

상태: 눌림 `primary-active`, 비활성 `primary-disabled`. 포커스는 2px `focus` 링. 초록 버튼은 한 화면에 하나만 두세요.
