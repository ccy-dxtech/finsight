### [🟡 minor] A06 · supabase/migrations/0001_init.sql:81 `commit_analysis` RPC가 한도·건수·월 검사 없이 `authenticated`에 열려 있음
근거: `grant execute ... to authenticated`(132행). 함수 본문은 `auth.uid()` 검사 뒤 바로 insert와 `usage +1`을 한다. 월 한도 검사는 `src/app/api/analyze/route.ts:56`에만 있고, 3,000건 상한은 `normalize.ts:67`에만 있다. `p_month`는 호출자가 정한다.
악용: 로그인한 Free 사용자가 브라우저에서 `supabase.rpc("commit_analysis", …)`를 반복 호출하면, 월 한도와 3,000건 상한을 건너뛰고 `transactions`에 행을 무제한으로 쌓아 공용 Postgres 용량을 소진시킬 수 있다. AI 호출은 일어나지 않으므로 비용 피해는 없다.
→ Fix: 새 마이그레이션 `0002`에서 함수 안에 다음 검사를 넣는다.
```sql
if jsonb_typeof(p_transactions) <> 'array'
   or jsonb_array_length(p_transactions) not between 1 and 3000 then
  raise exception 'Invalid transactions' using errcode = '22023';
end if;
-- 월은 p_month 대신 서버 시각(KST)으로 정하고, usage 행을 for update로 잠근 뒤 plan별 한도(free 3 / pro 30)를 넘으면 raise
```

### [🟡 minor] A06 · src/lib/statement/parse.ts:32 xlsx `<dimension>` 선언 범위를 그대로 믿고 빈 셀까지 전부 펼침
근거: `sheet_to_json(sheet, { header: 1, defval: "", blankrows: true, range: 0 })`. xlsx는 `<dimension ref>`를 `!ref`로 그대로 쓴다. 3,000건 상한은 파싱이 끝난 뒤에야 걸린다.
악용: 로그인한 사용자가 `<dimension ref="A1:XFD1048576"/>`만 넣은 수 KB짜리 .xlsx를 `/api/analyze`에 올리면, 빈 문자열 약 170억 개를 만들다가 함수를 300초 동안 점유하거나 OOM을 일으킨다. 실패는 횟수에서 차감되지 않으므로 반복할 수 있다.
→ Fix:
```ts
const range = XLSX.utils.decode_range(sheet["!ref"]);
range.s.r = 0;
range.e.r = Math.min(range.e.r, MAX_SHEET_ROWS - 1);   // 예: 5000
range.e.c = Math.min(range.e.c, range.s.c + MAX_SHEET_COLS - 1); // 예: 50
return XLSX.utils.sheet_to_json<string[]>(sheet, { header: 1, raw: false, defval: "", blankrows: true, range });
```

### [🟡 minor] A06 · src/lib/statement/pdf.ts:117 PDF 쪽 수 상한 없이 모든 쪽의 글자를 추출함
근거: `readPdfRows`는 `extractTextItems` 전에 쪽 수를 확인하지 않는다. 검사는 4MB 크기 제한뿐이다.
악용: 4MB 안에서 수천 쪽이 같은 압축 스트림을 참조하도록 만든 PDF를 올리면 함수가 장시간 점유된다.
→ Fix:
```ts
const pdf = await getDocumentProxy(new Uint8Array(buffer));
if (pdf.numPages > MAX_PDF_PAGES) throw new Error("too_many_pages");
const { items } = await extractTextItems(pdf);
```

### [🟡 minor] A02 · next.config.ts:3 보안 응답 헤더 없음 (클릭재킹 방어 없음)

    { key: "X-Frame-Options", value: "DENY" },
    { key: "X-Content-Type-Options", value: "nosniff" },
    { key: "Referrer-Policy", value: "strict-origin-when-cross-origin" },
  ] }];
}
