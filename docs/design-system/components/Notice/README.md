# Notice

화면 안에 놓이는 안내 박스예요(토스트가 아니에요).

- 기본 `fs-notice`: 결제 확인 중, 이미 분석한 파일 같은 중립 안내.
- `fs-notice--success`: 결제 완료 같은 좋은 소식.
- `fs-notice--error`: 형식 오류, 5MB 초과, 3,000건 초과, 열을 못 찾음, AI 실패. **항상 "횟수는 차감되지 않았어요"를 덧붙여요.**
- `fs-testnote`: 요금제·결제 버튼 바로 아래 "테스트 결제 환경이며 실제로 청구되지 않습니다".

첫 문장은 굵게, 무슨 일이 있었는지. 둘째 문장은 사용자가 할 일. 색만으로 의미를 전하지 않도록 아이콘(i / ✓ / !)을 함께 써요.
