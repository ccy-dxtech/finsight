# AppSidebar

대시보드 공통 내비게이션(ADR-017). 1024px 이상은 왼쪽 240px 사이드바, 그보다 좁으면 같은 마크업이 64px 상단 바가 돼요.

- **넓은 화면**: 위에서부터 로고 → 메뉴(홈 / 월별 추이 / 설정) → 맨 아래 플랜 카드. 바탕 `canvas`, 오른쪽 1px `hairline`. 화면 높이에 붙어(`sticky`) 본문을 스크롤해도 그대로예요.
- **메뉴 한 줄**: 높이 44px, `radius-pill`, 왼쪽에 `lucide-react` 아이콘 20px(`strokeWidth` 1.5, `body`), 글자 `nav-link`. 현재 메뉴는 `aria-current="page"`이고 바탕 `surface-strong`, 글자 `ink` 600. 리포트 상세는 "홈"에 속해요.
- **잠금 배지**: 무료 사용자의 "월별 추이" 오른쪽 끝에 `Badge` lock "프로".
- **플랜 카드**: `radius-xl`, 1px `hairline`, 안쪽 16px. 한 줄에 "현재 플랜"(`caption`, `muted`)과 플랜 배지(무료 기본 / 프로 `pro`)만 둬요. 한도 설명과 "프로 구독하기"는 홈 플랜 카드와 설정의 플랜 행이 맡아서, 사이드바에는 겹쳐 두지 않아요(잠금 카드·소진 카드에서도 구독할 수 있어요).
- **좁은 화면**: 로고와 플랜 배지가 한 줄, 메뉴가 그 아래 줄(640px 이상이면 한 줄). 아이콘과 "현재 플랜" 글자는 숨겨요.
- 루트는 `<header>`(배너 랜드마크), 메뉴는 `nav[aria-label="대시보드"]`예요.
