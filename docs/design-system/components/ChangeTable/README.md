# ChangeTable

카테고리별 전월 대비 증감 표(프로). 열: 카테고리 / 그 전달 / 최근 달 / 증감. 머리에는 실제 달 이름을 쓰고, 오늘이 아니라 거래가 있는 가장 최근 달과 그 전달을 비교해요. 전달 거래가 없으면 표 대신 그달 명세서를 올리라는 안내와 "명세서 올리기"를 둬요.

증감은 지출 증가 `change-up`(빨강, ▲ +), 감소 `change-down`(파랑, ▼ −), 변화 없음 `muted`. 색만으로 의미를 전하지 않도록 기호와 부호를 항상 같이 써요. 금액은 모두 `fs-num`(고정폭 숫자)으로 오른쪽 정렬.
