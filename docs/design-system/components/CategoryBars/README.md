# CategoryBars

카테고리 차트는 가로 막대 목록이에요. 모든 막대는 `primary` 한 색이고 이름·금액·비율이 막대 옆에 직접 붙어서 범례가 필요 없어요(원형 차트를 쓰지 않아요).

리포트 상세와 대시보드 홈에 같은 카드를 써요. 대시보드에서는 가장 최근 리포트의 지출이고, 제목 아래 `body-sm` `muted` 한 줄에 "가장 최근 리포트 · 파일 이름 · 기간"과 텍스트 버튼 "리포트 보기"를 붙여요.

금액 내림차순. 고정 10개 카테고리(식비 / 카페·간식 / 교통 / 쇼핑 / 구독·정기결제 / 주거·통신 / 의료·건강 / 문화·여가 / 교육 / 기타) 중 0원인 것은 숨겨요. 가장 큰 항목의 막대를 100%로 맞춰요.
